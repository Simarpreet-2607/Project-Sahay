# Sahay – Disaster Intelligence & Response Platform | Flask, Python, SQL, REST APIs, Cloud
• Developed web platform to support disaster awareness and emergency response through multiple user-facing
services.
• Implemented a regression-based rainfall prediction module to analyze river and weather data and generate risk
alerts with performance metrics such as MAE and R2
.
• Built RESTful APIs using Flask to handle user requests, validate data, and serve prediction results and alert
notifications.
• Designed features including a blood donation information portal, emergency contact system with email
notifications, and a 24/7 chatbot for user assistance.
• Integrated river-level monitoring to trigger alerts when water levels crossed predefined thresholds, helping users stay
informed about potential flood risks.
